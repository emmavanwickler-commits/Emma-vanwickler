# Emma Van Wickler — Personal Website

## Publish with GitHub Pages
1. Download and unzip this folder.
2. Upload `index.html` and the `assets` folder to the root of your GitHub repository.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`, then save.
6. Your site will publish at your GitHub Pages URL.

Keep the `assets` folder beside `index.html`; the page loads the portrait from `assets/emma-portrait.jpg`.

The website content is based on the information on your current site. Check dates and details before publishing if anything has changed.
